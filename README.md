# kitty

> Kitty terminal emulator config files

---

Simply clone this repository into `~/.config/kitty` to use my settings!

The colors are Callie's, from [greylocklabs/themes](https://github.com/greylocklabs/themes):
`callie.conf` is a copy of its `ports/kitty/callie.conf`.
